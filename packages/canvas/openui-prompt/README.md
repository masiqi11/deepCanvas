# @deepseek-ai/dsh-openui-prompt

English | [中文](README.zh.md)

## Summary

The plugin adds one system prompt section: the OpenUI Lang reference for the components the client renders, the rules for composing an interface, and worked examples. The model then answers in Markdown and writes interfaces in `openui` fences inside the reply. The reference is generated from the client library, so the prompt and the renderer stay in step.

## Use this package

Add the plugin to an agent preset and compose [the renderer](../ui-openui/README.md) in the Web profile:

```yaml
- id: openui-prompt
  name: '@deepseek-ai/dsh-openui-prompt'
```

<a id="model-experience"></a>
## Model Experience

### openui:reference

#### What the model sees

The `openui:reference` section opens with `Replies are Markdown.` and then gives the OpenUI Lang syntax, component signatures, functions, actions, streaming order, three worked examples, and the composition rules.

#### Token effect

About 9,000 static tokens per request.

#### KV Cache effect

The section is static per preset, so it stays in the cached prefix.


## Known Limitations and Deferred Work
